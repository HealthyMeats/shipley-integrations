# Code of Conduct

Be decent to each other.

This is a small project run by a farm. We expect the same behaviour here that we would expect
from someone standing in our store: treat people with respect, assume good faith, and take
disagreements as technical rather than personal.

Not welcome: harassment, personal attacks, discriminatory language, or persistently pushing
past a clear "no" from a maintainer.

If someone is making this project worse to be part of, email <gray@shipleyfarmsbeef.com>.
Reports stay private. We will handle it, and the range of outcomes runs from a quiet word to
a permanent ban. We would rather lose a contributor than keep a hostile one.
