# Contributors

People who have improved Shipley Farms' public tools. Newest first.

This file exists so a contribution here is **citable**. A merged pull request on GitHub is
public and permanent, and your name below is a plain record that we accepted it. If you are a
student and someone asks us to confirm you contributed, we will.

We are not going to inflate anyone's work. A typo fix is listed as a typo fix and a shipping
integration is listed as a shipping integration. That honesty is what makes the list worth
being on.

## How to get on this list

Have a pull request merged. That is the whole requirement. There is no minimum size, and the
first task on <https://shipleyfarmsbeef.com/helloworld> counts.

Maintainers: add a row when you merge, in the same commit as the merge where practical. Use the
contributor's preferred name and link their GitHub profile if they want it linked. Ask first
rather than assuming; some people contribute under a name they do not want indexed.

## What we will and will not say about your work

**We will:** confirm that you contributed, describe what you built, and say whether we use it.
If you need that in writing for a course or an application, ask.

**We will not:** write you a personal reference on the strength of a pull request alone, or
describe a contribution as larger than it was. If you work with us long enough that a real
reference makes sense, that is a different conversation and a welcome one.
